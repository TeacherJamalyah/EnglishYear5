GitHub Pages Export Guide

Publish your Year 5 English app for free online!

Langkah 1: Salin Kod (Copy Code)

Tekan butang Copy Complete HTML Code di bawah untuk menyalin kod aplikasi ini.

Langkah 2: Buat Repositori di GitHub

  1. Buka github.com dan log masuk.
  2. Tekan ikon "+" -> "New repository".
  3. Namakan repositori (contoh: year5-english-hub).
  4. Pilih Public, tanda "Add a README file", kemudian tekan Create repository.

Langkah 3: Tambah Fail index.html

  1. Klik Add file > Create new file.
  2. Namakan fail sebagai index.html.
  3. Tampal (*paste*) kod yang telah disalin.
  4. Tekan butang hijau Commit changes....

Langkah 4: Aktifkan GitHub Pages

  1. Pergi ke Settings > Pages (menu sebelah kiri).
  2. Di bahagian Branch, tukar kepada main, lalu klik Save.
  3. Tunggu 1 minit, pautan permainan web anda sedia digunakan!
